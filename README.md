# LinguaChat

**LinguaChat** — PWA-приложение для изучения иностранных языков с использованием искусственного интеллекта.

Приложение позволяет вести диалог с AI, автоматически определять язык сообщения, получать перевод с учётом контекста и выполнять упражнения для практики языка.

## Возможности

* 🌍 Автоматическое определение языка сообщения
* 💬 Чат с AI в формате языкового помощника
* 🔄 Перевод между русским и изучаемым языком
* 📖 Перевод отдельных слов в формате словаря
* 🎓 AI-генерация заданий для изучения языка
* 📊 Отслеживание уровня владения языком
* 💾 Сохранение истории диалога
* 📄 Работа с PDF-документами
* 📱 Progressive Web App (PWA)
* 👤 Сессионная идентификация пользователя без обязательной регистрации

## Как работает приложение

### 1. Определение языка

Пользователь отправляет сообщение. Backend передаёт запрос в LLM, которая определяет язык сообщения и использует настройки пользователя для выбора языка перевода.

### 2. Перевод

В зависимости от языка исходного сообщения приложение выполняет перевод:

```text
Русский → Изучаемый язык
Изучаемый язык → Русский
```

Перевод выполняется с учётом контекста диалога.

### 3. Работа с отдельными словами

Для отдельных слов используется специальный режим, который возвращает перевод в формате словарной статьи.

### 4. Обучение

AI может генерировать упражнения на основе сообщений пользователя и текущего уровня владения изучаемым языком.

Результат используется для дальнейшей практики и обновления информации об уровне пользователя.

## Установка

### Клонирование репозитория

```bash
git clone https://github.com/mrMoish/LinguaChat.git
cd LinguaChat
```

### Backend

Создайте виртуальное окружение:

```bash
cd backend

python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте переменные окружения:

```env
OPENROUTER_API_KEY=your_api_key
DATABASE_URL=your_postgresql_url
```

Запустите сервер:

```bash
uvicorn main:app --reload
```

Backend будет доступен по адресу:

```text
http://localhost:8000
```

### Frontend

В отдельном терминале:

```bash
cd frontend

npm install
npm run dev
```

После запуска Vite приложение будет доступно по адресу:

```text
http://localhost:5173
```

## API

Основные API-эндпоинты:

| Метод  | Endpoint            | Назначение                  |
| ------ | ------------------- | --------------------------- |
| `GET`  | `/api/history`      | Получение истории сообщений |
| `POST` | `/api/chat`         | Отправка сообщения в AI     |
| `POST` | `/api/lesson`       | Генерация учебного задания  |
| `POST` | `/api/check_lesson` | Проверка ответа на задание  |

Для идентификации сессии используется HTTP-заголовок:

```text
X-Session-Id
```

## База данных

Приложение использует PostgreSQL.

Основные таблицы:

* `chat_history` — история сообщений
* `documents` — загруженные документы
* `user_settings` — настройки пользователя и уровень языка
* `lesson_logs` — история учебных заданий

## OpenRouter

Для работы AI используется API OpenRouter.

Модель задаётся на стороне backend и используется для генерации переводов, ответов и учебного контента.

Для запуска необходимо указать:

```env
OPENROUTER_API_KEY=your_api_key
```

## PWA

LinguaChat реализован как Progressive Web App.

Это позволяет устанавливать приложение на поддерживаемые устройства и использовать его как обычное приложение.

Frontend содержит конфигурацию PWA через Vite plugin.
